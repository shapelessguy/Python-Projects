# Filme

Das ist die Filmbibliothek – der Hauptordner der fertigen Filme (`{{output}}`), derselbe, den Plex als **Movies** zeigt.

- Links einen Film auswählen, um ihn hier abzuspielen, mit jeder seiner Audio- und Untertitelspuren.
- Mit dem Feld oben suchen. Die Ordner werden beobachtet: Was außerhalb von CyanHouse hinzukommt, erscheint von selbst.
- Filme kommen fertig hier an: Sie werden zuerst in einem Vorbereitungsbereich aufbereitet und dann hierher verschoben.
{{#publish}}- Du kannst einen Film auf einen anderen Tab ziehen, um ihn dorthin zu verschieben; Plex wird automatisch benachrichtigt.
{{/publish}}
